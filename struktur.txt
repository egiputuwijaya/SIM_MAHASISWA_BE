sim_mahasiswa_be/

│
├── models/
│   ├── Database.php        # Wrapper class PDO (opsional tapi rapi)

│   ├── MahasiswaModel.php  # Query SQL terkait tabel mahasiswa (+ view profil)

├── uploads/

│
├── .htaccess               # Pengaturan URL Rewriting (Clean URL / Front Controller)
